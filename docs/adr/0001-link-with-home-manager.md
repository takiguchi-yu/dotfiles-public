# ホームへのリンクは home-manager の mkOutOfStoreSymlink で張る

fish など一部の設定はすでに home-manager で管理していたので、リンクの仕組みも home-manager に寄せ、管理の仕組みを 1 つにした。`mkOutOfStoreSymlink` を使うと、ホームの設定は nix store ではなくリポジトリの作業ツリーを直接指す。そのため、ツールや人がホーム側で編集した内容は、`home-manager switch` をやり直さなくてもリポジトリに反映される。代わりに、リポジトリの置き場所は固定のパスになる。

## Considered Options

- **自作の install.sh**: nix に依存しない。ただし home-manager と合わせて、管理の仕組みが 2 つになる。
- **GNU stow**: リポジトリを、パッケージごとのディレクトリ構成に作り直す必要がある。
- **chezmoi**: 秘匿値のテンプレート機能はある。ただしリンクではなくコピーする方式で、ツールがホームで書き換えた内容がリポジトリに戻らない。

## Consequences

- ツールがファイルを一時ファイル経由で書き換えると、リンクが普通のファイルに置き換わることがある。これは**取り込み**で戻す。
- `~/.claude/hooks` などはディレクトリごとではなく、1 件ずつリンクする。外部スキルや業務専用ファイルが、public リポジトリの作業ツリーに入らないようにするため。自作スキルとエージェントは別リポジトリに移した（ADR 0003）。
