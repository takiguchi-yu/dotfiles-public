# 自作スキルは別リポジトリ claude-skills に置き、リンクで入れる

自作スキルとそのエージェント（complete-task と ct-* のエージェントなど）は、dotfiles から切り出して [claude-skills](https://github.com/takiguchi-yu/claude-skills) に置いた。スキルは評価用のデータや参考資料を持ち、単独で改良を重ねていく成果物で、設定とは変わる理由が違うため。claude-skills は 1 ディレクトリに 1 つのスキルと、それが使うエージェントを入れ、自前の `install.sh` で `~/.claude` にリンクする。dotfiles の `setup.sh` は、それを clone して呼ぶだけにした。ADR 0001 では、管理の仕組みを 1 つにするために自作の install.sh を採らなかった。claude-skills では、dotfiles（と nix）が無くても単独で入れられることを優先した。

## Considered Options

- **Claude Code のプラグイン**: スキルとエージェントを 1 つの単位として配れる。ただし呼び出し名が `/プラグイン名:スキル名` に変わり、インストールしたものはコピーなので、編集がすぐには反映されない。配布する予定がないので、今は採らない。ディレクトリの中身はプラグインと同じ並びにしてあるので、移るときはマニフェストを足すだけで済む。
- **skills CLI（`npx skills add`）**: 他のエージェントにも配れる。ただしサブエージェントの定義は扱えない。
- **dotfiles のまま**: スキルとエージェントが別々のディレクトリに分かれ、どれとどれが組なのかが見えない。
