# public のまま運用し、秘匿値はローカル設定に切り出す

このリポジトリは public のまま運用する。秘匿値（実名、メールアドレス、業務上の名称やパス、トークンなど）はリポジトリに入れず、セットアップのときに入力して**ローカル設定**に書き出す。リポジトリ側の設定は、そのローカル設定を読み込む（git の include など）。読み込み機構を持たないツール（Claude Code の settings.json、Copilot CLI の mcp-config.json）は、公開分とローカル設定を合成して生成する。Claude Code の `--settings` で重ねる案もあったが、IDE や他のツールから起動したときに業務の設定が効かないため採らなかった。業務専用ファイル（業務システム向けのスキルやフック）は、値だけを切り出すことができないので管理しない。漏れを防ぐため、このリポジトリの pre-commit で gitleaks を実行する。

## Considered Options

- **private に変更**: 手間はいちばん少ない。ただし、これまで public だった履歴は取り消せず、公開して共有できる利点もなくなる。
- **public と private の 2 本**: 業務専用ファイルも管理できる。ただし、リポジトリを 2 本運用する手間に見合わないと判断した。
