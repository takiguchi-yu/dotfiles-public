# ホームとリポジトリの対応表。setup.sh / import.sh / links.nix がこのファイルだけを読む。
#
#   link    <ホームのパス> [<リポジトリのパス>]  ファイルかディレクトリをそのままリンクする
#   each    <ディレクトリ>                       直下の項目を 1 件ずつリンクする
#   compose <ホームのパス> <ローカル設定名>      公開分とローカル設定を合成して生成する（リンクしない）
#   ignore  <ホームのパス（glob）>                取り込みの対象にしない
#
# パスはすべてホーム起点。<リポジトリのパス> を省くと同じパスを使う。
