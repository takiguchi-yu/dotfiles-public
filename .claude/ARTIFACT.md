## HTML は Sumi Shu で組む

HTML（Artifact・ローカルのページ・GitHub Issue の HTML artifact）を出力するときは、`sumi-shu` スキルを読み、自分用のデザインシステム **Sumi Shu** で組む。archify・html-plan の出力も、同じスキルの「第三者スキルに寄せる」の節で配色を寄せる。依頼が無くても読む。正本は公開リポジトリ claude-skills の `sumi-shu/skills/sumi-shu/`。

`artifact-design` スキルや `frontend-design` スキルの見た目の指示（題材ごとに配色や書体を選ぶ、本文を 65 文字幅前後にする など）より、`sumi-shu` スキルを優先する。65ch は日本語では全角 32 字前後（約 500px）になり、広い画面で細くて読みにくいため。

完了条件: 出力した HTML が、`sumi-shu` スキルの「仕上げの検査」（第三者スキルの出力は「第三者スキルに寄せる」の確かめ）を満たす。
